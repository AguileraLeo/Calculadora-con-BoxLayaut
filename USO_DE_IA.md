# Uso de Inteligencia Artificial

Durante la creación de este proyecto se utilizó Inteligencia Artificial como herramienta de apoyo durante el proceso de desarrollo y aprendizaje.

## Forma de utilización

La Inteligencia Artificial fue utilizada principalmente como asistente para comprender y solucionar problemas que aparecieron durante el desarrollo del proyecto.

Entre las tareas en las que se recibió asistencia se encuentran:

* Resolución de errores durante la creación y ejecución del proyecto.
* Orientación sobre la estructura y organización de los archivos.
* Ayuda para comprender y corregir problemas relacionados con Git.
* Orientación en la configuración del archivo `.gitignore`.
* Explicación de comandos utilizados para administrar el repositorio.
* Ayuda para realizar el primer commit del proyecto.
* Apoyo en la creación y organización de la documentación del proyecto.

## Errores y problemas durante el desarrollo

A lo largo de la creación de la calculadora aparecieron distintos problemas relacionados con la configuración del proyecto y el uso de Git.

La Inteligencia Artificial fue utilizada para analizar estos errores, explicar sus causas y proporcionar instrucciones paso a paso para solucionarlos.

Entre los problemas abordados se encuentra la configuración inicial de `.gitignore`, la exclusión del entorno virtual `.venv` del control de versiones y la configuración de la identidad de usuario de Git necesaria para realizar commits.

Por ejemplo, Git inicialmente no permitía realizar el commit porque no se había configurado el nombre y correo electrónico del usuario. Este problema fue identificado y solucionado mediante la configuración correspondiente de Git.

## Propósito del uso de IA

La Inteligencia Artificial se utilizó como una herramienta de apoyo educativo y técnico. Su función fue ayudar a comprender los errores y proporcionar orientación durante el desarrollo, mientras que la ejecución de las instrucciones y el desarrollo del proyecto se realizaron en el entorno local.

## Declaración

El proyecto fue desarrollado por el autor con apoyo de Inteligencia Artificial durante diferentes etapas del proceso. La IA fue utilizada principalmente para resolver errores, comprender conceptos y comandos, y mejorar la documentación del proyecto.
